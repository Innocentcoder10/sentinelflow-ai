# SentinelFlow AI

## Governed Agentic AI for SOC Alert Triage & Incident Investigation

SentinelFlow AI is a cybersecurity decision-support system designed to assist Security Operations Centre analysts with alert triage, evidence correlation, threat intelligence enrichment, risk prioritisation and incident investigation.

The system uses Agentic AI while retaining human approval for high-impact security actions.

## Core Capabilities

- SOC alert triage
- Alert correlation
- Threat intelligence enrichment
- Asset context enrichment
- Risk prioritisation
- Incident investigation
- Human-in-the-loop approval
- Escalation
- Audit logging
- Open-model comparison
- AI governance and guardrails

## Technology Stack

- Python
- Streamlit
- n8n
- Ollama
- Open-weight LLMs
- ChromaDB
- SQLite
